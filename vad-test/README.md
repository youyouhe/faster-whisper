# VAD 静音检测程序

一个基于Python的VAD（Voice Activity Detection）程序，用于检测WAV音频文件中的静音段。

## 功能特点

- 检测音频文件中的静音段（非语音活动部分）
- 支持自定义检测参数
- 输出详细的静音段时间信息
- 支持多种输出格式（JSON和时间戳文件）
- 提供静音时长统计信息

## 依赖安装

```bash
pip install librosa numpy
```

## 使用方法

### 基本使用

```bash
# 检测默认文件66.wav
python vad_detector.py

# 检测指定文件
python vad_detector.py audio_file.wav
```

### 参数说明

- `input_file`: 输入音频文件路径（默认：66.wav）
- `-o, --output`: 输出结果文件路径（默认：silence_detection.json）
- `-t, --threshold`: 能量阈值，0-1之间（默认：0.01）
- `-d, --duration`: 最小静音持续时间，秒（默认：0.5）
- `-f, --frame-length`: FFT窗口大小（默认：2048）
- `-l, --hop-length`: 帧移（默认：512）

### 使用示例

```bash
# 检测所有静音段（默认参数）
python vad_detector.py 66.wav

# 提高检测敏感度，检测更多静音段
python vad_detector.py 66.wav -t 0.005 -d 0.2

# 只检测明显的静音段
python vad_detector.py 66.wav -t 0.02 -d 1.0

# 自定义输出文件
python vad_detector.py 66.wav -o my_results.json

# 高分辨率检测
python vad_detector.py 66.wav -f 1024 -l 256
```

## 输出文件

程序会生成两个输出文件：

1. **JSON文件**（如：`silence_detection.json`）
   - 包含完整的检测结果和参数配置
   - 每个静音段的开始时间、结束时间和持续时间
   - 总静音时间和静音占比统计

2. **时间戳文件**（如：`silence_detection_timestamps.txt`）
   - 简洁的时间戳列表
   - 格式：开始时间\t结束时间\t持续时间
   - 便于其他程序处理

## 算法原理

程序使用以下步骤检测静音段：

1. **音频加载**：使用librosa加载WAV文件
2. **短时能量计算**：计算音频帧的能量
3. **能量归一化**：将能量值归一化到0-1范围
4. **静音检测**：低于阈值的帧标记为静音
5. **静音段合并**：将连续的静音帧合并成静音段
6. **时长过滤**：过滤掉持续时间不足的静音段

## 参数调优建议

- **能量阈值（-t）**：
  - 降低值（如0.005）：检测更多静音段，更敏感
  - 提高值（如0.02）：只检测明显的静音段，更宽松

- **最小静音时长（-d）**：
  - 减小值（如0.2）：检测短暂的停顿
  - 增大值（如1.0）：只检测较长的静音段

- **FFT参数**：
  - 较小的窗口（如1024）：更高时间分辨率，但可能影响检测准确性
  - 较大的窗口（如4096）：更好频率分辨率，但时间精度降低

## 注意事项

- 支持的音频格式：WAV
- 采样率：自动检测，支持各种采样率
- 音频时长：建议不超过30分钟以保证处理速度
- 内存使用：对于长音频文件，需要足够内存

## 技术细节

- **采样率**：自动从音频文件读取
- **窗口函数**：使用汉宁窗进行STFT
- **能量计算**：基于STFT幅度的平方和
- **时间精度**：由hop_length参数决定，默认为512/采样率秒
